Support

Need help with Reef Tank? Read the project documentation or open a GitHub issue.

For a bug report, include your Roku model, Roku OS version, app version, and what happened. GitHub issues are public: do not include passwords, signing keys, device identifiers, or private contact information.

Fish density, camera drift, and day/night behavior can be adjusted in the screensaver settings.
