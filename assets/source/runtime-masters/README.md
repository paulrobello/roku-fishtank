# Lossless runtime masters

Preserved from the pre-certification runtime assets at commit `70d8e24`.
These are generated derivatives of the existing approved artwork; original
provenance remains under the sibling source folders. These PNGs are never
packaged. `tools/art/store_art.py` produces the smaller store-ready textures
without resizing. Update these masters only from newly generated full-quality
art, never by copying already encoded runtime files back here.
